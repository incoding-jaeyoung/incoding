🌟 View Transitions API란?

View Transitions API는 웹 페이지 간의 부드러운 전환 애니메이션을 만들 수 있는 최신 웹 표준 API입니다. 복잡한 JavaScript 라이브러리 없이도 네이티브 브라우저 기능만으로 아름다운 페이지 전환을 구현할 수 있습니다.

⚡ 성능 최적화

브라우저 네이티브 구현으로 최고의 성능을 제공합니다.

🎯 간단한 구현

CSS 몇 줄만으로 복잡한 전환 애니메이션을 구현할 수 있습니다.

♿ 접근성 지원

prefers-reduced-motion을 자동으로 처리하여 접근성을 보장합니다.

🔍 SEO 친화적

실제 페이지 네비게이션을 유지하여 SEO에 유리합니다.

💻 구현 코드

/* CSS에 한 줄만 추가하면 끝! */
@view-transition {
  navigation: auto;
}
